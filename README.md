# **Garry's Mod Lua Addons**

## **Addon List**

### **Tood's ALCS Lootboxes v3**
- Create lootboxes with configurable NPC drops.
- Includes damage system to prevent free loot.
- Set NPCs that drop lootboxes.
- Grant players XP for opening lootboxes.
- Custom chat messages for received items.

**Configuration**:  
Drop the folder into your `addons/` folder, then go to `toods_alcs_lootboxes_v3/lua/autorun/sh_wos_t_config.lua`.

**STEAM LINK: https://steamcommunity.com/sharedfiles/filedetails/?id=1927142025**

### **Tood's Chat Games v1**
- Random questions are posted to chat every X minutes, players must answer to earn rewards.
- Staff ranks can trigger games using a chat command.

**Configuration**:  
Drop the folder into your `addons/` folder, then go to `toods_chat_games/lua/chatgames_main/sh_t_chatgames_config.lua` for config options.

**STEAM LINK: https://steamcommunity.com/sharedfiles/filedetails/?id=3157788102**

### **Tood's Dropship Tool v2.2**
- Create customizable dropships that spawn NPCs and "fly" in/out.
- Destructible dropships with configurable class, models, HP, and weapons.

**Configuration**:  
All configuration is done in-game. Open the spawnmenu and select "Dropship Tool" to edit the values.

**STEAM LINK: https://steamcommunity.com/sharedfiles/filedetails/?id=3353953693**
